## Cursor Cloud specific instructions

### Project overview

Bulldog Trading Bot — a Python 3.12+ cryptocurrency futures trading bot for BTC/USDT on Poloniex. See `README.md` for full details.

### Running the application

- **Bot (paper trading):** `source .venv/bin/activate && python bot.py` — connects to Poloniex public API for live price data. No API keys needed for paper mode. The bot runs in an infinite loop (5-minute candle intervals); use `Ctrl+C` or `timeout` to stop.
- **Backtest (full):** `python backtest.py` — fetches historical data from Binance public API starting from 2022. This takes a very long time (10+ minutes) due to the volume of data fetched.
- **Backtest (fast variants):** `python backtest_fast.py`, `python backtest_turbo.py`, `python backtest_ultra.py` — require a pre-existing `historical_data.csv` (generated by running `backtest.py` first).

### Dependencies

All Python dependencies are in `requirements.txt`. The virtual environment lives at `.venv/`.

### Lint / test / build

This project has no configured linter, test framework, or build system. Validate by running `python -c "from config import config; from strategy import Strategy; from strategy_bulldog import BulldogStrategy; print('OK')"`.

### Caveats

- `bot.py` requires network access to Poloniex even in paper trading mode (for live price data).
- `backtest.py` requires network access to Binance's public API.
- No `.env` file is committed; API keys are read from environment variables `POLONIEX_API_KEY` and `POLONIEX_API_SECRET` (only needed for live trading).
- The `.gitignore` excludes all `*.json` files except `package.json`, so `paper_state.json` is not tracked.
